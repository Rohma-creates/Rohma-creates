## 📱 Projects

### 🩺 CarbSense
A Flutter app mainly for people with Type 1 diabetes, and a helpful tool for people on a diet as well. For diabetics, daily insulin is already set by their doctor, but when they eat something extra, they need to know its carbohydrates to work out the extra insulin. CarbSense shows the carbs in a chosen food and an approximate meal dose based on the user's own insulin-to-carb ratio.

- Food database organized by category, with carb values per serving
- Approximate dose calculation using the user's insulin-to-carb (IC) ratio
- Diet mode for anyone who wants to track their carb intake

**Status:** Beta, currently being tested by users

**Coming next:** based on tester feedback, user accounts and a cloud database so both diabetic users and people on a diet can save and track their meals over time.

> ⚠️ For informational purposes only. Not a substitute for medical advice.
